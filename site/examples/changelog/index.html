Milestone 03

Admin and Go core#

20:07 to 20:51

Breaking
Breaking change · 20:51

The server now needs the new dumpsd binary before you can publish. Run dumps install-dumpsd on the server once, then publish as usual.

The top bar, footer and Open Graph tags are now injected on the server, so a server running the older binary would serve pages without them.

Added 1

  • 20:32

    Admin in the browser: archive, unarchive, rename and delete dumps, protected by Cloudflare Access.

Changed 4

  • 20:51

    The top bar, footer and Open Graph injection moved into the Go binary on the server.

  • 20:51

    Thumbnails are taken from the raw page, as you wrote it.

  • 20:32

    The CLI and the admin share one lock, so their edits never overlap.

  • 20:07

    dumpsd, a Go binary, is now the single writer of the home page and the listing. Its output is byte-identical to before.

Fixed 2

  • 20:51

    Read-only files no longer get in the way of publishing.

  • 20:07

    Concurrent publishes no longer lose updates.
