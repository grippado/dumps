02 · Style dial

Say how far to push. In plain words.

Content and accessibility never move with the dial. Only the art direction does. Nothing said means bold. An art direction in prose works too, like the one that made this page.

Dump it. Say it like: nothing at all, "make it nice", "ousado".

Each level is a preview of the type treatment, not a full page.

03 · Opinions

It refuses the default artifact look.

Never

  • Centered gradient hero plus three cards
  • Emoji as icons or bullets
  • Drop shadows on everything
  • Titles that only name a topic

Instead

  • The answer, verdict or key number first
  • Real data only, never invented
  • Light and dark both designed
  • Readable at 360px, keyboard accessible
04 · What you get

Six reasons it lands.

A

A specialist, not a template.

Eight recipes, each written from the point of view of the person who would make that page for a living.

B

One file.

A self-contained index.html that works offline once loaded.

C

Plain-word dial.

Classic for the board, avant-garde for "go wild".

D

Your domain, your call.

With dumps installed, the page publishes hidden to your own domain. You click Publicar in the admin when it is ready for the home page.

E

Works without a server.

No dumps? You get an artifact, a canvas or a file.

F

Open source, MIT.

Part of the dumps repository on GitHub. Read it, fork it, change its opinions.

05 · Install

Four harnesses. Pick yours.

Claude Code

From a clone of the dumps repository:

cli/dumps install-agent claude

Then ask with /dump-this.

Codex

cli/dumps install-agent codex

Then ask with /prompts:dump-this.

claude.ai

Upload the skill in Settings, Capabilities, Skills:

grippado.github.io/dumps/dump-this.zip

ChatGPT

Paste the instructions into a custom GPT or a Project:

grippado.github.io/dumps/dump-this-chatgpt.txt
06 · How it works

Install. Ask. Ship the page.

  1. 1

    Install the skill

    In whichever of the four harnesses you already use.

  2. 2

    Ask in your words

    "/dump-this landing page for the dump-this skill, Swiss poster style." That request made this page.

  3. 3

    Get the page

    As an artifact, canvas or file. With dumps, as a hidden link on your domain until you click Publicar.

Stop shipping the default look.
