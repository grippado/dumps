The idea

Any HTML artifact, a file or a folder, becomes your link.

This is the whole product in one sentence. Self hosted, your domain, one command or one agent call. Everything after this slide is how.

How it works

One small Go binary does the whole job.

1

You publish

dumps publish a file or a folder, or ask your agent.

2

dumpsd prepares

Adds a share bar, a footer and Open Graph previews to the page.

3

It goes live atomically

Activated in one swap with rollback; the home and the private admin listing are rendered by a single writer.

Admin API behind Cloudflare Access or Tailscale. Runs on Android (Termux), Linux (systemd), macOS (launchd) or fully local.

Stress atomic with rollback: a half written page never goes out. Single writer means the home and admin listing never race.
