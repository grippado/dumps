# Recipe: comparison (think like a decision advisor)

Use when choosing between options: tools, vendors, designs, plans.

1. **Verdict first.** A recommendation box: which option, for whom, and the one reason that
   decided it.
2. **Criteria.** List the criteria with a weight or a "must have" mark before scoring.
3. **Table.** Options as columns, criteria as rows, short text cells (not just checkmarks).
   Mark the best cell per row. Sticky first column on phones.
4. **Per option.** A short card each: best for, watch out for, cost.
5. **What would change the decision.** One paragraph.
