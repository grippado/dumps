# Recipe: changelog (think like a release manager)

Use for release notes or "what shipped this week".

1. Versions or dates newest first, each as a section with an anchor.
2. Inside each, group by Added, Changed, Fixed, Removed. One line per change, user facing
   wording, link to the PR or issue when available.
3. Highlight breaking changes in a warning box with the migration step.
4. A short summary paragraph at the top of the latest version.
