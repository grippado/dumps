# Security policy

Please report vulnerabilities privately through GitHub security advisories: open the Security tab of the repository and choose "Report a vulnerability". Do not open a public issue for security problems.

Include what you found, how to reproduce it, and the version of `dumpsd` (`bin/dumpsd version`). We will acknowledge the report and follow up in the advisory thread.

For the threat model and deployment advice, see [docs/security.md](docs/security.md).
